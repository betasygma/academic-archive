# ITS Environment 3D Scene

A WebGL 2-based 3D scene and animation of a selected area around the ITS campus
for Computer Graphics Assignment 2.

## Project Repository

The implementation and its project documentation are maintained in a separate
repository:

[betasygma/its-environment-3d-scene](https://github.com/betasygma/its-environment-3d-scene)

This archive preserves the assignment context and brief rather than duplicating
the project files.

## Assignment Context

| Field | Details |
|---|---|
| Course | Computer Graphics |
| Assignment | Assignment 2 |
| Semester | 5 |
| Technology | WebGL 2 |
| Team members | Mikail Ibrahim Hakim; Bara Semangat Rohmani |

The assignment is to create an animation featuring objects from an area of the
ITS campus outside the Informatics Engineering Department. The project applies
3D transformations, camera configuration, lighting, textures, and hierarchical
modelling.
