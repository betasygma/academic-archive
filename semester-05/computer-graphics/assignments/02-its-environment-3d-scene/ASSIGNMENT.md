# Assignment 2: Creating a Scene of an Area Around ITS (Outside the Informatics Engineering Department)

## Objective

Students are expected to be able to apply transformations, camera, lighting, and texture to 3D objects, as well as hierarchical modelling using WebGL.

## Assignment Requirements

1. The assignment must be completed in groups of no more than two students.
2. The implementation must use WebGL.
3. The assignment must be completed within three weeks.
4. Only one student per group is required to submit the assignment.

## Assignment Description

1. Create an animation featuring several objects located within the ITS campus environment.
2. The submission must include the main application page containing the following components. Only one student per group is required to submit the assignment.
   - Group name.
   - Photographs of the actual objects.
   - Videos of the actual objects.
   - The application's canvas page. The canvas should be positioned near the reference images, where possible, to make the similarity between the actual objects and the implementation easier to observe.
   - A tree diagram illustrating the hierarchical relationships between objects.
   - Task distribution among group members.

## Assessment Criteria

<ol type="a">
<li>Complexity.</li>
<li>Similarity to the real objects.</li>
<li>Task distribution.</li>
<li>Lighting and texture.</li>
<li>Ability to explain the implementation.</li>
<li>Ability to solve challenges.</li>
</ol>
