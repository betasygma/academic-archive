## Repository Status

Use the following status values consistently:

| Status          | Meaning                                            |
| --------------- | -------------------------------------------------- |
| **Active**      | Repository is still being developed or maintained  |
| **Completed**   | Work is finished but repository remains available  |
| **Archived**    | Work is finished and no longer expected to change  |
| **Deprecated**  | Repository has been replaced by another repository |
| **Unavailable** | Repository can no longer be accessed               |

## Notes

* This file contains **references to external repositories**, not copies of their contents.
* The repository URL should point to the canonical location whenever possible.
* If a repository is moved, update the URL here and preserve the original context.
* Avoid duplicating large files from external repositories in this archive unless there is a specific archival reason.
* Use relative links for files that are stored inside this academic archive.
* Record the repository's status when the link is added or reviewed.
