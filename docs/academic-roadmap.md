# Academic Roadmap

This document describes the academic progression throughout the undergraduate Informatics Engineering program.

The roadmap focuses on how foundational knowledge developed into core Computer Science concepts and, subsequently, into more specialized areas.

It is organized chronologically by semester while highlighting the relationships between courses and broader areas of study.

---

## 1. Overview

The academic journey can be broadly viewed as:

```text
Foundations
    ↓
Programming & Computer Systems
    ↓
Core Computer Science
    ↓
Software, Data & Intelligent Systems
    ↓
Advanced & Specialized Computing
```

The progression is not strictly linear. Several areas develop in parallel and later converge in projects and applied coursework.

## 3. Semester 2 — Core Computing Foundations

### Main Focus

* Data structures
* Operating systems
* Computer organization
* Numerical computation
* Mathematical continuation

### Courses

| Course                | Primary Area                               |
| --------------------- | ------------------------------------------ |
| Calculus 2            | Applied Mathematics                        |
| Data Structures       | Algorithms & Programming                   |
| Operating Systems     | Computer Systems                           |
| Computer Organization | Computer Systems                           |
| Numerical Computation | Applied Mathematics & Scientific Computing |

### Development

The second semester builds on programming and mathematical foundations while introducing the internal organization and operation of computing systems.

```text
Fundamental Programming
```

```text

Operating Systems
```


## 6. Semester 5 — Specialization and Integration

### Main Focus

* Modeling and simulation
* Framework-based software development
* Computer graphics
* Information security
* Knowledge-based systems
* Requirements engineering
* Multivariate data analysis
* Software evolution

### Courses

| Course                              | Primary Area                               |
| ----------------------------------- | ------------------------------------------ |
| Modeling and Simulation             | Applied Mathematics & Scientific Computing |
| Framework-Based Programming         | Algorithms & Programming                   |
| Computer Graphics                   | Computer Graphics                          |
| Information Security                | Cybersecurity                              |
| Knowledge-Based Systems Engineering | Artificial Intelligence                    |
| Requirements Engineering            | Software Engineering                       |
| Multivariate Data Analysis          | Statistics & Data Analytics                |
| Software Evolution                  | Software Engineering                       |

### Development

Semester 5 emphasizes integration, specialization, and more advanced application of previously established concepts.

Examples:

```text
Mathematics
     +
Statistics
     +
Computing
     ↓
Modeling, Simulation & Data Analysis
```

```text
Artificial Intelligence
     +
Knowledge Representation
     +
Software Engineering
     ↓
Knowledge-Based Systems
```

```text
Software Development
     +
Software Design
     +
Requirements
     ↓
Software Evolution
```

The curriculum increasingly emphasizes not only how to build software, but also how to analyze, model, secure, maintain, and evolve computational systems.

## 10. Overall Progression

The academic journey can be summarized as:

```text
Semester 1
Foundations
    ↓
Semester 2
Core Computing Foundations
    ↓
Semester 3
Core Computer Science
    ↓
Semester 4
Integration & Advanced Core
    ↓
Semester 5
Specialization & Integration
    ↓
Semester 6
Advanced Coursework
    ↓
Semester 7
Specialization & Major Projects
    ↓
Semester 8
Capstone & Completion
```

This roadmap represents the development of academic knowledge over time. It does not represent a ranking of semesters, courses, or competencies.
