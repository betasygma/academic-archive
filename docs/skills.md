# Skills

This document tracks the technical skills developed throughout the undergraduate Informatics Engineering program.

Skills are organized by technical area and supported by coursework, projects, and practical work where applicable.

The purpose of this document is to show **development and evidence**, not to assign subjective proficiency scores.

## 14. Evidence Principle

A skill should ideally be associated with evidence.

Possible evidence includes:

* Coursework
* Practical assignments
* Projects
* Source code
* Jupyter notebooks
* Experiments
* Reports
* Presentations
* Portfolio repositories
* Technical documentation

Example:

```text
Machine Learning
├── Coursework
│   └── Machine Learning
├── Notebooks
│   └── ...
├── Experiments
│   └── ...
└── Portfolio Project
    └── ...
```

The `skills.md` file should be updated as new coursework and projects provide additional evidence.
